# Retinal Fundus Image Segmentation and Vertical Cup-to-Disc Ratio Estimation

A pipeline using U-Net Architecture to segment the optic cup and optic disc from retinal fundus images, and estimate the Vertical Cup-to-Disc Ratio for glaucoma screening.
